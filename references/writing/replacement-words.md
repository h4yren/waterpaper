# 核心替换词库

按此词库逐条修改AI腔写法。

---

## 一、立场表达

| AI腔写法 | 学者真实写法 | 出处 |
|---------|------------|-----|
| 值得商榷 | 我们不赞成；大有疑问；实不足取 | 陈光中、黄明涛、李双元 |
| 可以认为 | 我们认为；笔者以为；本文认为 | 陈光中、高铭暄、黄明涛 |
| 有一定道理 | 这一观点有其合理的部分；诚然…… | 陈光中、张翔 |
| 需要指出的是 | 恰恰；但问题恰在于；殊不知 | 黄明涛、苏力 |
| 这种说法不够准确 | 这种论断大有疑问；犯了"白马非马"的错误 | 陈光中 |
| 不可忽视 | 不可或缺；岂非荒谬 | 陈光中 |
| 有学者认为（无来源） | 诚如某某所言（加脚注） | 李双元 |
| 这种观点值得商榷 | 实不足取；大有疑问 | 李双元 |
| 固然；当然 | 诚然；固然后者 | 张翔、陈端洪 |

---

## 二、转折与推进

| AI腔写法 | 学者真实写法 | 说明 |
|---------|------------|------|
| 但是 | 然而；恰恰；其实；殊不知 | "然而"正式；"恰恰"带锋芒 |
| 综上所述 | 可见；由此；质言之；一句话 | 推进而非总结 |
| 简而言之 | 质言之（黄明涛）；换言之 | 古典精炼感 |
| 也就是说 | 换言之；毋宁说 | 换言之更书面 |
| 更准确地说 | 毋宁说；确切地讲 | 布迪厄/强世功译法 |
| 由此可见 | 由此（直接推进，不做收尾） | 布迪厄高频用法 |
| 虽然……但是…… | 固然……然而……；诚然……但 | 让步后真正转折 |

---

## 三、程度副词（多数应删除或具体化）

| AI腔写法 | 处理方式 |
|---------|---------|
| 非常重要 | 删除副词，直接说重要在哪里 |
| 较为普遍 | 给出数字或案例，或删除 |
| 进一步 | 说清楚推进了什么 |
| 一定程度上 | 要么说清程度，要么删除 |
| 相对而言 | 相对于谁？说清楚 |

---

## 四、古语与成语的精准嵌入

**规则**：只能在能精确描述一个论证节点时用，不做装饰；一篇论文不超过3处。

| 情境 | 可用表达 | 出处 |
|-----|---------|-----|
| 批驳对方混淆不同层次的概念 | 犯了"白马非马"的错误 | 陈光中 |
| 指出某论断自相矛盾 | 掩耳盗铃；岂不是自相矛盾 | 黄明涛、陈光中 |
| 说明对抗式辩论有助于发现真相 | 兼听则明，偏听则暗 | 陈光中 |
| 描述某人做了某事却声称没做 | 掩耳盗铃（精确用法见黄明涛） | 黄明涛 |
| 反驳某个极端假设的荒谬性 | 岂非荒唐（接具体案例） | 陈光中 |
| 说明标准随时代变过 | 以古例对比今日判断，不加解释 | 李双元 |

## 五、学者词汇速查表

这些词汇在原文中高频出现，代表前AI时代法学论文的真实用词习惯：

### 起论与推进
- **质言之**（黄明涛）——段落的精华句前置标记，相当于"说到底"
- **毋宁说**（布迪厄/强世功）——在两种说法之间做精确选择
- **恰恰**（强世功）——指出表面悖论背后的深层一致
- **坦率地说**（苏力）——营造直接对话感的口语化插入
- **事实证明**（黄明涛）——比"可见"更有历史纵深感
- **恐怕**（黄明涛）——有把握但保持学术谦逊，不是"可能"

### 让步与辩驳
- **诚然**（多人）——让步的典雅表达，比"固然"略轻
- **固然……然而……**（张翔、陈端洪）——让步结构的标准搭配
- **不无道理**（张翔）——有节制地承认对方合理性
- **何其相似**（张翔）——用于类比时加强感情色彩

### 批驳
- **大有疑问**（黄明涛）——比"值得商榷"更有力度
- **实不足取**（李双元）——四字断语，斩截有力
- **岂非荒唐**（陈光中）——反问收尾，把论证转化为读者自己的判断
- **掩耳盗铃**（黄明涛）——精确描述"做了某事却声称没做"这一学术行为

### 归纳与收束
- **可见**——比"综上所述"简洁，且可以推进而非仅总结
- **由此**（布迪厄）——真正的步骤推进，不是赘词
- **一句话**（陈光中偶用）——极简收束，有口语感
